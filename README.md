# Munchkin Online Prototype

Run this from this folder:

```bash
npm install
npm run dev
```

This version includes 1.0:

- landing page
- bot-count select
- dice order preview, but the human player is forced first for testing
- setup dealing 4 Door and 4 Treasure cards to each player
- Level 1 starting characters
- Kick Open The Door
- monster combat
- curse resolution
- Look For Trouble
- Loot The Room
- Charity hand limit of 5
- basic item/class/race playing
- basic one-shot combat cards
- Run Away on 5 or higher

Bots and multiplayer are intentionally not implemented yet. Bot turns can be skipped from the board.
